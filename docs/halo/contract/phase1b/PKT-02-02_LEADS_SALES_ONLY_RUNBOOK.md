## Three proof layers (keep separate throughout)

1. **UI-definition proof** — the builder configuration (fields, filters, dealer, period, filter summary). Captured *before* retrieval. No rows, no PII.
2. **Raw-byte proof** — the exported native file's magic/type, filename, SHA-256, size, capture ID, source/final URL host. No rows rendered.
3. **Row-content proof** — counts, per-Lead-ID multiplicity, duplicate/blank profiles, timestamp parseability, unique Lead Type/Source/Source Group values, and zero Service/Parts. Values are profiled, **never** rendered as PII.

Never let a later layer's evidence stand in for an earlier one (a clean derivative cannot prove the raw; row counts cannot prove the UI filter).
